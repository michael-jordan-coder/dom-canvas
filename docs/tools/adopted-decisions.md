# החלטות שאנחנו מאמצים

החלטות שהתקבלו מתוך [מחקר הכלים](README.md), עבור DOM Canvas ו-Sketchpad. כל החלטה מציינת מאיפה היא באה ומתי לממש אותה.

## 1. הסתרת אלמנטים קטנים לפי זום

**ההחלטה:** כשמתרחקים בזום, מסתירים אלמנטים שגודלם על הקנבס קטן מסף מסוים. ככל שהזום רחוק יותר, הסף גדל.

| זום מתחת ל- | מוסתרים אלמנטים קטנים מ- |
| --- | --- |
| 0.4 | 7.5 פיקסלים |
| 0.2 | 15 פיקסלים |
| 0.1 | 30 פיקסלים |
| 0.05 | 60 פיקסלים |
| 0.025 | 120 פיקסלים |

- **הגודל נמדד בפיקסלים של הקנבס,** לפני הזום. בזום 0.4, אלמנט של 7.5 פיקסלים תופס על המסך פחות משלושה פיקסלים, כך שלא רואים אותו בכל מקרה.
- **מסתירים עם `visibility: hidden`,** ולא מוציאים מה-DOM. ככה הפריסה לא משתנה, ואין צורך לבנות את האלמנט מחדש כשחוזרים לזום קרוב.
- **המקור:** הטבלה לקוחה מקוד העורך של Paper. ראו [Paper, סעיף 7](paper.md).
- **מתי לממש:** כשיהיו על הקנבס עשרות פריימים אמיתיים והזום הרחוק יתחיל להאט. לא לפני כן.
